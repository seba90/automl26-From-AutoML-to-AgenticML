# Experiment A1 — LLM Surrogate, No Explanations

Same baseline, same data as [A0](A0.md). Here the hyperparameter proposer is
an LLM agent instructed to pick new values each generation *without*
explaining its reasoning — just numbers in, AUC out, repeat.

A1 is **not** meant to be run from a fixed list of commands: it needs an LLM
in the loop deciding each generation's hyperparameters, one generation at a
time, informed by the previous generation's outcome. Hand the LLM agent
shell access to this repo and give it the prompt below — not per-generation
commands, since those are exactly what the LLM is supposed to produce
itself.

**Example prompt:**

```text
Run a new experiment. Take `models/model_dcnv2.json` again. Run 10 generations.
This time, instead of using the Bayesian process, you are the surrogate
model — you decide which hyperparameters to try. Don't explain your
choices, just suggest new hyperparameters after each iteration. Call this
experiment `A1`.
```
