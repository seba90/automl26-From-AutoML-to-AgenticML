# Experiment A4 — Feature Transformation, Especially String Features (DCN²)

Baseline: `models/model_dcn2.json` (requires DCN² support from [A2+A3](A2_A3.md)
to already be implemented). Same protocol as [A1](A1.md)/A2+A3's search loop,
but the LLM's job this generation is feature engineering, not hyperparameter
tuning: keep every existing feature, and see whether *transforming* the raw
features — especially the categorical (originally string) ones — adds signal
that the model's own cross layer doesn't already capture on its own.

A4 is **not** meant to be run from a fixed list of commands: it needs an LLM
in the loop deciding what to try each generation, informed by the previous
generation's result. Hand the LLM agent shell access to this repo and give it
the prompt below.

Unlike A0–A2+A3, this one can't run on the bundled `data/criteo_01.csv.gz` —
that file is already murmur3-hashed, so the raw categorical strings
transformation is supposed to act on aren't available. Download the full raw
dataset first with `scripts/download_data.sh full` (`-> data/train.txt`,
~4.6 GB compressed) and preprocess it before starting the experiment.

**Example prompt:**

```text
Run a new experiment. Take `models/model_dcn2.json` as the base. Keep all
features — don't drop any — but see if you can transform the features,
especially the string (categorical) features, to improve the model. Download
the full dataset first with `scripts/download_data.sh full` and preprocess
it, since the bundled 1% sample is already hashed and has no raw string
features left to transform. Run 10 generations, explaining your hypothesis
and next step at each one. Call this experiment `A4`.
```
